# 모델 입력 확인

평가 결과에서 선택한 사진의 **실제 전처리 값과 모델 입력**을 확인합니다. 전처리 설정을 바꾸거나 OCR을 다시 채점하는 기능은 아닙니다.

```sh
pnpm install
pnpm dev
```

1. 평가가 끝나면 샘플 이미지를 눌러 확대창을 엽니다.
2. **모델 입력 확인**을 누릅니다.
3. 원본과 실제 중간 단계, 최종 입력의 shape·dtype·최솟값·최댓값을 확인합니다.
4. 필요하면 **상세 정보**를 눌러 같은 입력의 학습·평가 모드 shape를 비교합니다.
5. 닫으면 평가 결과로 돌아갑니다.

화면에서 다른 학습 폴더를 선택해 두었더라도 **선택한 결과를 만든 평가의 Python·보고서·체크포인트·설정**을 사용합니다. 해당 파일이 없거나 평가 당시의 해시와 다르면 이유를 표시합니다. 별도의 정답 파일이나 캡처 루트 입력은 없습니다.

## 실제 전처리 관찰

지원하는 현재 ldb-ocr 함수의 실행에서 `rgb`, `inverted`, `normalized`, `output` 배열을 관찰합니다. 실제 순서는 RGB → 반전 회색조 → 정규화 → 패딩이며 resize 단계는 없습니다. 외부 전처리 소스를 수정하거나 계산식을 화면용으로 복제하지 않습니다.

단계 이름과 순서를 검증한 전처리 소스만 지원합니다. 보고서·실행 소스의 해시와 NumPy·Paddle 버전, 전처리·pooling 정보가 달라지면 다른 처리로 대체하지 않고 거부합니다.

관찰 기능은 실제 함수의 return frame에서 배열 복사본을 얻고 즉시 해제됩니다. 평가와 진단은 같은 모델 입력 준비 함수를 사용합니다. 단계별 shape·dtype·값 범위는 관측값이며, 패딩 경계는 실제 콘텐츠와 출력 크기로 표시합니다.

정규화된 값의 PNG는 **표시용 미리보기**입니다. 표시 변환 방법을 각 단계에 적고 원래 값 범위를 함께 보여줍니다. 변환된 이미지나 확대된 이미지는 모델에 넣지 않습니다.

## 상세 shape

다음 세 지점만 실제 실행에서 관찰합니다.

- 모델 입력
- pooling 직전
- pooling 직후

선택한 학습 결과의 모델과 pooling 정책을 유지하며, 별도 진단 인스턴스에서 gradient 없이 backbone을 실행합니다. 학습·평가 모드는 같은 초기 모델 상태와 동일한 입력에서 시작합니다. 진단 hook과 모델 자원은 종료 시 정리합니다.

확인한 shape가 다르면 해당 행을 강조합니다. 관측하지 못한 지점은 **확인하지 못함**으로 표시하며 실패를 일치로 처리하지 않습니다. 이 결과는 동일 입력의 모드별 shape 비교이며 학습 데이터 생성·augmentation이나 모델 전체의 정상 여부를 판정하지 않습니다.

상세 관찰 지점은 현재 검증한 `PPLCNetV3` 소스와 해당 pooling 구현에 한정됩니다. backbone 앞에 Transform이 있거나 관찰 지점의 코드가 다른 모델은 shape를 추측하지 않습니다.

Windows의 실제 사용자 체크포인트(`adaptive40`)와 합성 ROI에서 다음 값을 관측했습니다. 이 크기는 실행 결과이며 다른 입력의 결과를 대신 표시하는 고정값이 아닙니다.

| 확인 지점    | 학습 모드         | 평가 모드         |
| ------------ | ----------------- | ----------------- |
| 모델 입력    | `[1, 3, 48, 384]` | `[1, 3, 48, 384]` |
| pooling 직전 | `[1, 480, 3, 96]` | `[1, 480, 3, 96]` |
| pooling 직후 | `[1, 480, 1, 40]` | `[1, 480, 1, 40]` |

관찰 전후 최종 입력의 값·shape·dtype 일치, 표시용 변환의 입력 불변성, 모드별 초기 상태 복원과 원본 파일 해시 유지도 확인했습니다. 실제 라벨 데이터셋이나 다른 pooling 정책의 Windows 실행까지 검증한 것은 아닙니다.

## 범위와 제한

앱의 현재 평가 결과에 포함된 사진 한 장만 확인합니다. 평가 실행 중에는 진단할 수 없으며 진단 중에는 새 평가를 실행하지 않습니다. 중단하면 앱이 소유한 진단 프로세스만 종료합니다.

취소·실패한 평가에서도 이미 처리되어 보고서에 저장된 샘플은 필요한 실행 정보가 있으면 확인할 수 있습니다. 처리되지 않은 사진이나 실행 정보가 없는 이전 보고서는 대상이 아닙니다.

원본 PNG·정답·보고서·체크포인트·학습 설정·문자 사전은 수정하지 않습니다. 진단 결과는 화면에만 표시하며 별도 보고서·이력·내보내기를 만들지 않습니다. 필요한 원본 소스나 실행 환경을 사용할 수 없거나 관찰 지점을 지원하지 않으면 오류 또는 미확인 상태를 표시합니다.
